# Math-kid
Using the Hand Wirttien Mnist dataset to build a hand recognition web app using Deep Learning.
MathKid is a project that aims to help kids improve their math skills by recognizing their handwritten digits. This project uses deep learning techniques to build a web application that can identify and validate handwritten digits drawn by kids. The core functionality of MathKid is based on training a deep neural network on the Handwritten MNIST dataset, making it a fun and educational tool for children.

## 🚀 Features

- ✍️ Draw handwritten digits directly in the browser.
- 🧠 Deep learning model trained on the MNIST dataset.
- ⚡ Real-time digit recognition.
- 🎨 Interactive and kid-friendly interface.
- 📊 TensorBoard support for monitoring training performance.
- 🌐 Web-based application accessible from any device.

## 📂 Dataset

This project uses the **MNIST Handwritten Digits Dataset**, which contains 70,000 grayscale images of handwritten digits (0–9). The model learns to classify these digits with high accuracy.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Hassan-Shoayb//Math-kid.git
cd Math-kid
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Usage

1. Launch the web application.
2. Draw a digit (0–9) using your mouse or touchpad.
3. Click the **"Check Answer"** button.
4. The deep learning model predicts the digit you have drawn.
5. Enjoy learning mathematics in a fun and interactive way.

---

## 🧠 Model Training

The model was trained on the MNIST dataset using TensorFlow and Keras. Training performance can be visualized with TensorBoard:

```bash
tensorboard --logdir logs
```
